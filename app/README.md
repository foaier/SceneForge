# 镜造（SceneForge）

镜造（SceneForge）使用 Qt 6、C++20 和 QML/Qt Quick。当前实现包括本机作品资料库、单集/多集创作、全剧与单集简报、结构化剧本、多语言稿件及历史、创作圣经、离线自动保存、时长与规则型质量提示、基础影响追踪、手工镜头与文字视觉参考及稳定关联、作品资料包基础能力、作品复制/归档/移至系统回收站，以及首版 AI 文本创作候选流程。SQLite schema v1–v12 可逐版本备份迁移至 v13。AI 支持故事发展建议和逐字段采纳、创作圣经新增条目逐项采纳及既有条目字段级修改建议、单集/全剧剧本生成、续写、段落及全剧/整集/整场批量改写/压缩/扩写/润色/风格调整、1/3 个候选切换、逐段编辑、结构化分析建议和候选独立版本保存。批量改写按稳定段落身份生成候选，采纳前复核全部目标快照，并为受影响剧集保存原稿；新场景生成要求逐项核对角色目标、冲突、说话方式和地点规则后才能采纳。全剧生成会为每集生成可切换、逐集编辑的候选，确认后作为各集独立的候选版本保存，不覆盖正式剧本；生成后剧集身份/顺序或改写目标正文/范围变化会拒绝过期候选。发送前可手工补充背景资料。候选段落边界不同时，可从不同候选添加段落并编辑、排序、删除、拆分和合并组合稿。仍缺图片文件导入/生成、完整分镜/视觉资产打包、格式导入导出、资料包内容选择，以及影响追踪的完整跨模态验收。

## 构建

需要 CMake、Ninja、C++20 编译器和包含 Qt Quick、Qt Quick Controls、Qt SQL 的 Qt 6 安装。Qt 与 C++ 编译器必须使用相互匹配的工具链。

```powershell
cmake -S app -B app/build -G Ninja -DCMAKE_PREFIX_PATH="<Qt安装前缀>"
cmake --build app/build
```

也可以在 Qt Creator 中打开 `app/CMakeLists.txt`，选择与 Qt 安装相匹配的构建套件。

## 验证

```powershell
ctest --test-dir app/build --output-on-failure
```

存储技术验证原型位于 `app/prototypes/storage-probe`，运行方法和验证边界见其中的 README。
