# RFC-006：专业剪辑、特效与媒体处理

## 摘要

本文定义面向短剧和动画成片的专业级剪辑与媒体处理能力。目标是让创作者能在一条连续工作流内编排视频、动画、对白、音乐、音效、字幕和图形，执行精细剪辑、视觉合成、调色、进阶特效和成片检查。

本 RFC 的“专业级”指可完成完整短剧制作和复杂镜头处理的创作能力，不以某个现有软件的界面或实现方式为要求。

该能力的最低验收范围由本 RFC 第 8 节定义；未达到其中验收场景的功能不视为已满足专业剪辑目标。

## 1. 用户工作流程

1. 用户创建或打开剪辑作品，选择单集或视频版本。
2. 用户从镜头、生成视频、录音、图片和已有媒体中添加内容。
3. 用户安排片段、声音、字幕、图形和效果，预览剪辑结果。
4. 用户执行精剪、调色、合成或专业效果处理。
5. 用户检查音画、字幕和画幅问题，保存版本并导出。
6. 用户可另建改编版本，保留原有剪辑成果。

## 2. 剪辑项目与时间线

- **REQ-EDIT-001**：剪辑项目应支持视频、动画、图像、对白、旁白、音乐、环境声、音效、字幕、标题和图形等内容类型。
- **REQ-EDIT-002**：用户应能在多条视频、音频、字幕和图形轨道上组织内容，并调整轨道顺序和可见状态。
- **REQ-EDIT-003**：用户应能按镜头、场次、连续片段或叠加元素分组管理时间线内容。
- **REQ-EDIT-004**：系统应提供按时间位置定位、播放、暂停、逐帧查看、循环预览和标记重点位置的操作。
- **REQ-EDIT-005**：用户应能创建、复制、命名和比较剪辑版本；一个版本的修改不得覆盖其他已保存版本。
- **REQ-EDIT-006**：系统应支持将角色、场次或镜头分组为可重复使用的内容单元；编辑该单元时应提示关联版本范围。
- **REQ-EDIT-007**：用户可以为剪辑项目添加注释、时间标记、待处理事项和完成状态。
- **REQ-EDIT-008**：系统应能定位时间线内容与原始镜头、剧本、声音和素材的关联。
- **REQ-EDIT-009**：用户可以为每个剪辑版本设置画幅、画面尺寸、帧率和声音声道，并查看其与素材和目标交付预设的差异。
- **REQ-EDIT-010**：时间线定位、剪切和片段边界应支持逐帧精确调整；用户可切换以帧或时间码查看位置。
- **REQ-EDIT-011**：用户可以使用预览副本编辑高分辨率素材，并在成片检查时确认预览与原素材的关联。
- **REQ-EDIT-012**：用户可以同步多机位素材、选择主画面或逐段切换机位，并检查画面与声音的同步。
- **REQ-EDIT-013**：系统应识别时间线上不同画幅或帧率的素材，并提示其与当前剪辑版本的适配方式和可能影响。
- **REQ-EDIT-014**：用户可以逐帧或按时间码设置片段标记点，并选择涟漪剪辑、滚动剪辑、滑移剪辑或滑动剪辑；执行前应显示会受影响的片段。
- **REQ-EDIT-015**：多机位剪辑应至少支持四路素材同步预览、声音同步检查和逐段切换机位。
- **REQ-EDIT-016**：用户可以按 SDR Rec.709 进行剪辑和成片检查；对 HLG 或 PQ HDR 素材，系统应识别并说明显示或输出转换的影响。
- **REQ-EDIT-017**：用户可以将代理预览结果替换回原素材完成输出，且应能检查代理和原素材的对应关系。
- **REQ-EDIT-018**：时间线位置应能以帧数或时间码显示；对 23.976、29.97 和 59.94 fps 项目，涉及 drop-frame 时间码时应明确标记时间码模式。

## 3. 精细剪辑操作

- **REQ-CUT-001**：用户应能裁切入点和出点、拆分、拼接、插入、覆盖、移动、排序、复制、替换和删除片段。
- **REQ-CUT-002**：用户应能对片段执行变速、倒放、定格、画面旋转、翻转、缩放、平移、裁切和画幅适配。
- **REQ-CUT-003**：系统应支持片段之间的转场、淡入淡出、叠化、遮挡和用户可调节的转场时长。
- **REQ-CUT-004**：用户应能锁定选定片段或轨道，避免批量操作误改已确认内容。
- **REQ-CUT-005**：移动、裁切或删除片段时，系统应按用户选择保持或改变其他轨道的时间关系，并明确显示操作影响。
- **REQ-CUT-006**：用户应能同步、解除同步和重新同步画面、对白、音效和字幕。
- **REQ-CUT-007**：系统应支持多机位素材的同步预览和机位选择工作流。
- **REQ-CUT-008**：用户应能按场次或镜头标记剪辑完成状态、待补镜头和替代素材。

## 4. 画面合成、调色与特效

- **REQ-FX-001**：用户应能调整画面位置、比例、旋转、透明度、裁切和混合方式。
- **REQ-FX-002**：用户应能为位置、比例、旋转、透明度、遮罩和常用效果设置关键帧，并预览关键帧之间的变化。
- **REQ-FX-003**：系统应支持基础曝光、色温、对比度、饱和度、色彩平衡、曲线或同等调色操作。
- **REQ-FX-004**：用户应能应用、组合、调整、隐藏和移除视觉效果，并比较处理前后的结果。
- **REQ-FX-005**：产品应支持常用遮罩、蒙版、抠像、背景替换、模糊、锐化、颗粒和画面风格处理。
- **REQ-FX-006**：产品完整目标应支持运动跟踪、画面稳定、复杂遮罩、逐帧修整和动态图形制作。
- **REQ-FX-007**：用户应能在文字、形状、标题、片头片尾、字幕和图像叠加中设置位置、样式和动画。
- **REQ-FX-008**：用户应能对特效设置作用范围和层级，并预览遮挡、混合和效果顺序。
- **REQ-FX-009**：系统应显示效果处理结果可能偏离创作圣经角色外观或视觉基调的提示。
- **REQ-FX-010**：特效处理应保留来源片段和原始版本，用户可以关闭效果或恢复处理前状态。
- **REQ-FX-011**：用户应能通过画面示波器或等效可视反馈检查亮度、色彩和曝光分布。
- **REQ-FX-012**：用户应能检查素材的色彩空间或动态范围信息；素材与输出色彩设置不匹配时应得到明确提示。
- **REQ-FX-013**：运动跟踪应能由用户指定跟踪对象、检查跟踪区域并修正跟踪偏移。
- **REQ-FX-014**：稳定、抠像、复杂遮罩和动态图形结果应能预览、局部修正和关闭，不得破坏性修改源素材。
- **REQ-FX-015**：专业调色应提供波形图、矢量示波器和直方图中的至少两种画面分析视图。
- **REQ-FX-016**：用户应能通过关键帧控制效果强度和遮罩变化，并检查关键帧间的运动结果。
- **REQ-FX-017**：色键抠像应支持选择取色区域、调整边缘和预览透明区域合成结果。

## 5. 音频后期

- **REQ-MIX-001**：用户应能在多条声音轨道中组织对白、旁白、环境声、音乐和音效。
- **REQ-MIX-002**：用户应能调整音量、左右声道平衡、淡入淡出、片段起止、同步位置和音频自动化。
- **REQ-MIX-003**：系统应支持常见声音均衡、压缩、降噪、混响、限幅和对白优先等处理。
- **REQ-MIX-004**：用户可以在对白出现时自动或手工降低背景音乐，并预览处理结果。
- **REQ-MIX-005**：系统应提示声音失真、过载、对白被遮盖、静音间隔和音画不同步。
- **REQ-MIX-006**：用户可以对比混音前后并保留多个混音版本。

## 6. 媒体处理工具

- **REQ-MEDIA-001**：用户应能查看导入媒体的基本属性和预览；基本属性至少包括时长、画面尺寸、帧率、媒体类型、文件大小，以及可识别的视频、音频和字幕轨道。
- **REQ-MEDIA-002**：用户可以执行常见媒体格式转换、压缩、尺寸调整、裁切、方向调整和批量处理。
- **REQ-MEDIA-003**：用户可以从视频提取关键画面或音频片段，作为场次、镜头或素材使用。
- **REQ-MEDIA-004**：用户可以拼接片段、合并声音、替换音轨和制作代理预览副本。
- **REQ-MEDIA-005**：批量操作开始前，用户应能检查选择范围、输出条件和可能的质量变化。
- **REQ-MEDIA-006**：媒体处理失败时应指出不兼容、损坏或不支持的项目，并保留源媒体和其他已完成结果。
- **REQ-MEDIA-007**：用户可以取消批量处理并检查已完成、未开始和失败项。
- **REQ-MEDIA-008**：处理后的媒体应保留与原始资产的来源关系和授权状态。
- **REQ-MEDIA-009**：导入素材兼容性应以用户可查看的媒体类型清单说明；不支持的文件应显示格式、原因和可行替代方式。
- **REQ-MEDIA-010**：导出或转换前，用户应能选择画面尺寸、帧率、画幅和音频输出方式，并查看预计质量变化。
- **REQ-MEDIA-011**：媒体属性检查应识别可读取的画面尺寸、帧率、位深、色彩范围/传递信息和音频采样率；无法确定时显示未知。
- **REQ-MEDIA-012**：产品应向用户说明受支持的媒体与剪辑工作负载范围，包括素材格式、单个素材和项目的规模、画面尺寸、帧率、色彩信息、单集时长和时间线轨道规模。对有限支持或待确认的素材，应指出具体字段及可能影响；有限支持的操作须经用户确认后才能继续。
- **REQ-MEDIA-013**：媒体兼容范围应区分已支持、有限支持、待确认和不支持。对有限支持的素材，系统应说明可执行的操作和已知限制；对待确认素材，不得表示其已受支持或可保证最终输出；对不支持的素材，不得执行受影响的处理或导出操作，应说明原因和可行替代方式。任何素材状态均不得仅凭“可导入”表述成“完整编辑及无损交付均受支持”。

## 7. 操作安全、检查和恢复

- **REQ-SAFE-001**：重要剪辑操作应可撤销和重做。
- **REQ-SAFE-002**：破坏性覆盖源素材或删除唯一版本前，系统应明确说明影响并要求用户确认。
- **REQ-SAFE-003**：系统应支持编辑历史、版本比较和恢复。
- **REQ-SAFE-004**：编辑或处理失败不得影响其他片段、声音或字幕。
- **REQ-SAFE-005**：成片检查应提示黑帧、空白片段、重复画面、静音、声音异常、画面抖动、比例错误、字幕遮挡和素材缺失。
- **REQ-SAFE-006**：检查项应能定位至具体轨道、片段和时间位置，并允许用户跳转处理。

## 8. 验收标准

- **AC-EDIT-001**：Given 一个镜头序列，When 用户进行拆分、重排和拼接，Then 可预览新顺序并撤销到原状态。
- **AC-EDIT-002**：Given 多条声音轨道，When 用户调整音乐和对白，Then 可分别试听并查看同步关系。
- **AC-EDIT-003**：Given 用户添加遮罩、跟踪或画面稳定效果，When 关闭该效果，Then 原片段与其他效果保持不变。
- **AC-EDIT-004**：Given 用户创建横屏改编版，When 调整画幅，Then 竖屏原版本继续保留。
- **AC-EDIT-005**：Given 用户进行多项批量格式处理，When 一项素材失败，Then 失败项可识别且其他成功结果可用。
- **AC-EDIT-006**：Given 时间线存在字幕遮挡或音画不同步，When 运行成片检查，Then 用户可定位到具体时间并返回编辑。
- **AC-EDIT-007**：Given 用户试图覆盖原始素材，When 操作会失去唯一源文件，Then 系统先说明影响并提供保留原件的选择。
- **AC-EDIT-008**：Given 用户切换剪辑版本，When 查看版本差异，Then 能识别镜头、声音、字幕和效果上的改变。
- **AC-EDIT-009**：Given 用户需要精确剪辑一帧，When 移动片段边界，Then 可以定位并确认该帧位置，且可撤销调整。
- **AC-EDIT-010**：Given 多机位素材和一条同步声音，When 用户建立剪辑段落，Then 可试听同步并逐段选择机位，源素材保持不变。
- **AC-EDIT-011**：Given 用户为画面设置关键帧，When 预览关键帧之间的变化，Then 能查看并修改各关键点而不影响其他片段。
- **AC-EDIT-012**：Given 用户使用跟踪、稳定或复杂遮罩，When 跟踪偏移或遮罩边缘不合适，Then 可局部修正并比较处理前后画面。
- **AC-EDIT-013**：Given 素材色彩信息与项目输出设置不一致，When 用户查看画面，Then 系统显示具体不匹配项和可能的视觉影响。
- **AC-EDIT-014**：Given 用户编辑高分辨率素材，When 使用预览副本完成剪辑，Then 成片检查能定位对应原素材并说明预览副本关系。
- **AC-EDIT-015**：Given 用户选择媒体导出格式，When 目标条件超出素材能力，Then 系统指出限制并提供可选尺寸或帧率。
- **AC-EDIT-016**：Given 用户执行涟漪、滚动、滑移或滑动剪辑，When 调整一个片段，Then 系统按所选操作影响相邻片段并可撤销恢复。
- **AC-EDIT-017**：Given 用户有五路同步机位素材，When 建立多机位片段，Then 可同时预览并逐段选取机位，切换后声音同步关系仍可检查。
- **AC-EDIT-018**：Given 一个 HLG 或 PQ 素材进入 SDR Rec.709 时间线，When 用户预览或导出，Then 系统说明转换结果并允许用户检查输出画面。
- **AC-EDIT-019**：Given 用户在波形图、矢量示波器和/或直方图查看画面，When 调整色彩，Then 至少两种可选分析视图与画面预览同步反映变化。
- **AC-EDIT-020**：Given 用户对绿幕片段执行色键抠像，When 调整取色和边缘，Then 可预览透明结果与背景合成并关闭效果恢复原片段。
- **AC-EDIT-021**：Given 用户在两个关键帧之间设置遮罩或效果强度，When 预览中间时刻，Then 效果变化连续可见且可修改关键帧。
- **AC-EDIT-022**：Given 素材属性无法识别，When 查看媒体信息，Then 对无法确定的字段明确显示未知，而不是给出猜测值。
- **AC-EDIT-023**：Given 用户为剪辑添加时间标记和待处理事项，When 切换剪辑版本，Then 标记能够定位到关联时间位置且不会改变片段内容。
- **AC-EDIT-024**：Given 用户调整片段位置、缩放、透明度和转场，When 预览组合效果，Then 每项效果都可单独调整、关闭和恢复。
- **AC-EDIT-025**：Given 用户锁定一条已确认轨道，When 执行涉及多条轨道的移动，Then 被锁定内容保持不动并明确提示未应用的变更。
- **AC-EDIT-026**：Given 用户进行素材同步、声音均衡和降噪，When 预览处理结果，Then 可对照原始音画并单独恢复某项处理。
- **AC-EDIT-027**：Given 成片含黑帧、静音和素材缺失，When 运行检查，Then 每项问题可定位到对应时间和轨道。
- **AC-EDIT-028**：Given 用户在 29.97 fps 项目使用 drop-frame 时间码，When 设置片段入点和出点，Then 时间位置无歧义且可逐帧定位。
- **AC-EDIT-029**：Given 某素材属于有限支持范围，When 用户准备执行该范围内的处理，Then 系统先说明支持限制和可能影响，经用户确认后才继续，且源素材及已有剪辑结果保持可用。
- **AC-EDIT-030**：Given 用户建立剪辑项目，When 查看项目支持范围，Then 可查到素材格式、单个素材和项目规模、画面尺寸、帧率、色彩信息、单集时长和轨道规模的支持状态；受限或未知项目不会被描述为完整支持。
- **AC-EDIT-031**：Given 用户选中的素材被标记为不支持，When 用户发起受影响的处理或最终导出，Then 该操作不会执行，系统说明具体原因和可行替代方式，其他可处理素材及原始文件保持可用。
- **AC-EDIT-032**：Given 某素材的关键属性待确认，When 用户检查或预览该素材，Then 系统标明未知属性，不将其描述为已支持；在该属性确认前，不将其纳入已验证的批量处理或最终导出范围。
