# 首阶段开发规格

## 1. 阶段目标

用户能够从一句创意、已有剧本、空白作品或模板开始，在本地建立单集短片或多集短剧，维护创作圣经、故事/剧本、场次和分镜，生成并审核参考图，检查一致性和素材来源，并导出剧本、分镜、参考图及选择的资料。没有 AI 配置或网络时仍可手工创作和使用本地已有内容。

首阶段范围依据用户确认的交付顺序：先完成剧本、分镜、参考图和基础媒体工具，再进入视频、声音和剪辑。RFC 的 P0/P1/P2 表示产品价值优先级，不是发布阶段；首阶段暂不包含部分 RFC 标为 P0 的能力，不代表这些能力从产品范围删除或被降级。

## 2. 范围

### 包含

- 资料库目录设置，作品存储单元创建/打开/复制/备份/恢复/归档/删除，保存和异常恢复状态；首阶段存储布局按 TASK-R002-000 原型结论执行，仅承诺本机 NTFS 目录和单进程写入，其他路径边界见[存储与数据模型](storage-and-data.md)。
- 从自由描述、导入剧本、空白或模板建立作品；缺少信息时可跳过并标记待决定。
- 作品/剧集、创作简报和创作圣经，包括角色、地点、道具、故事规则、状态和参考资料。
- 故事梗概、分集大纲、场次大纲和结构化剧本编辑；提供结构化 AI 操作及围绕当前作品/选中内容的上下文助手。AI 草案预览、差异比较、部分采用及版本恢复。
- 剧本格式适配目标：Fountain、Final Draft FDX、DOCX 导入/导出及 PDF 打印/导入。各格式只有在阶段 0 原型和依赖/发行许可门槛通过后才可进入实现；当前验证边界见下表和[DEC-003 格式调查](decisions.md#task-r002-016-剧本文档格式与依赖调查)。以剧本语义结构为保真基线，包括集顺序、场景标题、动作/场景描述、角色提示、对白、括号提示、旁白/画外音、音效/音乐提示和转场。跨格式不承诺页面布局、字体和分页完全一致；不支持的结构、FDX 扩展字段和预计损失必须在转换前逐项列出。PDF 原件始终保留；仅在文本提取依赖通过验证后，才可把可提取文本 PDF 识别结果供用户校正；扫描图片 PDF 保留原件并提示需人工整理，首阶段不承诺 OCR。

剧本格式的首阶段保真边界如下：

| 内容 | 首阶段要求 |
|---|---|
| 语义结构 | 导入/导出后可核对集顺序、场景标题、动作/场景描述、角色提示、对白、括号提示、旁白/画外音、音效/音乐提示、转场和段落顺序 |
| 版本与来源 | 保留原始导入文件；导入内容、候选、人工编辑稿和确认稿可区分并可追溯 |
| 页面呈现 | 可生成视觉 PDF 阅读/打印稿；跨格式不承诺字体、页码、分页、精确排版完全一致。画面可读不代表 PDF 文本可提取或符合 PDF/UA 可访问性 |
| 扩展与扫描 PDF | 未支持的 FDX 扩展字段逐项列出；可提取文本的 PDF 可供校正；扫描图片 PDF 只保留原件并标记需人工整理，首阶段不承诺 OCR |

格式目标不等于当前已验证能力：

| 格式 | 当前阶段 0 状态 | 开始实现前的门槛 |
|---|---|---|
| Fountain | 官方语法对照和合成样例已完成；候选解析器只做了 smoke test，未证明完整往返 | 明确支持语法子集、未知构造保留方式和损失预览 |
| FDX | 合成 XML 样例可解析；候选库丢失标题页、场景属性和双人对白，不能直接采用 | 使用真实 Final Draft/Fade In 样例验证版本、扩展和往返损失 |
| DOCX | 合成 OOXML 样例通过 ZIP/XML 及 python-docx 读取；libzip 1.12.1+zlib 1.4 的静态原型可读出包成员；没有真实 Word/LibreOffice 渲染或辅助技术验证 | 验证 MinGW 构建兼容规则、恶意/超大 ZIP 限制及发行声明；实测复杂版式、语义样式和校正流程 |
| PDF 文本导入 | 依赖未选；本机当前 Qt Gui 绘制样例的 pypdf 抽取结果为空，Qt PDF 模块未安装 | 选定提取器，验证实际文本层、顺序、乱码、损坏/加密和失败提示 |
| PDF 输出 | 当前仅证明可以生成视觉 PDF；未验证结构化标签或辅助技术兼容 | 如声明可访问 PDF，须验证标签结构及适用标准；否则明确为视觉打印稿 |
| 扫描 PDF | 不支持 OCR | 原文件保留并提示人工整理，不展示“识别成功” |

详细样例、版本、许可证及验证结果见[格式原型目录](../../app/prototypes/document-format-probe/README.md)。当前格式验证属于部分完成，不可作为对应导入/导出功能已通过验收的依据。

- 从剧本建立可编辑场次和镜头板；支持手工新增、排序、拆分、合并、复制和镜头关联；用自然语言简化视图与专业字段视图表达相同数据。
- 视觉参考图生成和导入；参考用途、角色/地点/镜头引用、候选比较、接受、拒绝、替换和重做。
- 内容质量、设定一致性、用户可配置的内容风险规则和来源/授权风险提示；首阶段针对剧本文本、生成要求和参考图开展可用检查。提示可定位并解释规则依据、影响范围、判断来源和不确定性；普通风险不阻止保存/导出，检查不得静默改写作品，也不得宣称保证平台或法律合规。记录用户填写与系统观察到的来源信息，并明确区分未知和未经系统验证的信息。
- 按能力配置文本/图片 AI 服务并允许单任务切换；外部请求授权、逐次发送范围确认、授权撤销、发送记录和已知/未知数据处理信息。
- FFmpeg/ffprobe 媒体探测、视频抽帧和轻量预览；素材属性未知时如实显示。
- 剧本打印稿、分镜/参考图导出和可重新打开的作品资料包；导出预览包括素材缺失、外部引用、权利风险和文件清单；来源清单、授权汇总和检查报告可选择是否纳入资料包。
- 中文主创作；英文版本可人工创建、对照编辑、与原文独立保存并独立导出。AI 翻译、字幕本地化和多语言声音工作流安排在阶段 3。

### 不包含

- 视频/动画生成、配音/声音克隆、音乐/音效生成、口型同步。
- 多轨时间线编辑、调色、转场、字幕制作、成片转码导出、运动跟踪、稳定、复杂遮罩/抠像和动态图形。
- 直接登录或发布到短视频平台、跟踪用户在平台上传页面的操作、账号运营和排期。
- 团队协作、云端项目同步、多用户冲突合并和在线账户系统。

这些是阶段安排，不代表从 RFC-001 至 RFC-008 删除相关完整产品目标。

## 3. 主要使用流程

### 新建到剧本

1. 用户选自由创意、导入、空白或模板入口。
2. 用户填写已知信息；未知字段可跳过，系统保留为待决定。
3. AI 整理候选创作圣经/故事大纲时显示服务、发送范围和候选目标。
4. 用户比较候选，选择部分接受或拒绝；正式设定和剧本只在用户确认后更新。
5. 用户编辑剧本、切换集/场次、检查时长和质量提示、比较/恢复版本。

### 上下文助手

用户可在作品、剧集、角色、场次、剧本段落、镜头或素材的工作上下文中提问并请求解释、分析或创作建议。发送给 AI 服务的上下文在提交前可查看和调整。助手的回答只是建议；用户明确要求生成或改写时，结果进入候选预览、比较和确认流程，不直接修改正式内容。

### 剧本到分镜

1. 用户选择剧本范围生成场次草案；未识别字段显示不确定。
2. 用户修正场次、地点、时间、角色和道具，选择保留剧本关联。
3. 用户生成或手工新增镜头；每个镜头关联场次、剧本段落、时长、画面、动作、构图和声音提示。
4. 用户运行连续性和时长检查，逐项查看问题、依据和影响。
5. 用户为角色、地点、场次或镜头生成参考图，比较并确认候选。
6. 用户导出剧本、分镜和可选参考图，或备份可重新打开的作品资料包。

### 媒体探测

用户导入本地视频/图片/音频后查看识别属性；可以按时间位置抽取静帧作为参考素材。探测和抽帧不改变源文件。源素材能力不确定时，可继续查看已识别内容，但相关字段显示未知。

## 4. 核心领域对象

| 对象 | 必需关联/状态 |
|---|---|
| Project | 类型、名称、语言、目标、保存状态、当前版本 |
| Episode | 作品 ID、顺序、目标时长、独立补充设定 |
| BibleItem | 分类、内容、确定/暂定/待决定/禁止改变状态、来源、版本 |
| ScriptBlock | 作品/集/场次、块类型、内容、顺序、来源关联 |
| ScriptVersion | 版本号、创建原因、父版本、作者类型、确认状态 |
| Scene | 集、剧本关联、地点/时间/角色/道具、预估时长、状态 |
| Shot | 场次、稳定 ID、显示顺序、描述、时长、镜头字段、待审状态 |
| Asset | 类型、路径/外部引用、hash、媒体属性、来源、授权状态 |
| AssetRelation | 源资产、衍生资产、角色/地点/场次/镜头引用、用途 |
| GenerationTask | 服务/能力、上下文 ID 列表、状态、尝试、候选资产 |
| CheckResult | 规则/版本、受影响对象、解释、严重度、用户处理状态 |

改变镜头顺序只改变显示顺序，不改变镜头稳定 ID；这样生成候选和资产不会挂到错误镜头上。

## 5. 首阶段功能验收

- **PH1-AC-001**：可分别通过一句创意、已有剧本、空白作品和模板创建单集或多集作品；向导问题可选、可自由填写或跳过；已选平台/发布预设仅作为可编辑建议；信息不全不会阻塞。
- **PH1-AC-002**：项目离线时可以打开、编辑、保存、查看已有素材和导出所选资料。
- **PH1-AC-003**：常见创作操作无需用户编写提示词即可发起；AI 提出的圣经或剧本变更先作为候选；拒绝候选后，正式内容不变。
- **PH1-AC-004**：剧本块可以人工编辑、移动、拆分和合并，原稿/候选/确认稿可区分，版本可比较和恢复。
- **PH1-AC-005**：在对应格式原型、依赖与发行许可门槛通过后，Fountain、FDX 和 DOCX 分别通过导入、结构校正和导出验收，集顺序及本阶段定义的剧本语义结构可核对；打印稿包含作品/作者/集信息、页码和版本等已选交付信息。页面布局、字体、分页和未支持扩展字段不承诺完全一致。转换预览逐项列出已知损失。PDF 原件不被覆盖；仅当已选文本提取器对代表性真实文本 PDF 通过验证后，识别结果才进入人工校正，场景标题、动作、角色提示及对白的不确定结构显示待确认；扫描图片 PDF 明确提示需要人工整理，不伪称已识别或承诺 OCR。视觉 PDF 的生成不自动表示文本可提取或符合 PDF/UA；若不满足可访问性验证，应明确标为视觉打印稿。
- **PH1-AC-006**：剧本拆分场次或镜头后，每个对象可追溯到原剧本；改变顺序不会改变其稳定关联；上游剧本变化会标记相关场次、镜头或参考图可能过期，并允许重新抽取或保留原值。
- **PH1-AC-007**：场次/镜头可逐项手工维护，并可在专业字段视图和自然语言简化视图之间切换；切换不丢失已填写信息；视图能显示同步、待审核或可能过期状态；不完整字段显示为待决定/待设计而不是自动填入事实。
- **PH1-AC-008**：一致性检查指出冲突双方、位置、规则依据和可采取动作；用户可将冲突标记为有意变化并留下说明；运行检查不改变作品。
- **PH1-AC-009**：图片服务任务确认前不发送请求；候选可比较、拒绝或接受；失败和取消不影响既有资产。
- **PH1-AC-010**：用户可设置文本与图片默认服务并在一次任务中改选；密钥不出现在作品数据库或导出资料包。
- **PH1-AC-011**：ffprobe 能报告可识别的属性，媒体可在首阶段支持范围内预览，抽帧结果关联源文件和时间位置；错误/取消不改变输入文件，不能把预览成功表述为完整编辑或交付支持。
- **PH1-AC-012**：资料库在只读、空间不足、丢失或不可访问时明确报告，不能显示为保存成功。
- **PH1-AC-013**：导出前显示所选内容、预计文件、缺失素材、外部引用和已知权利风险；用户可选择单集/全剧以及剧本、圣经、分镜、参考图、来源清单、授权汇总和检查报告等资料；导出中断后作品和已完成资料仍可用。
- **PH1-AC-014**：键盘、缩放、焦点和控件状态能覆盖主要创作和导出流程，满足 RFC-001 / NFR-A11Y-003 的适用要求。
- **PH1-AC-015**：用户填写的作者、来源、许可、使用限制、地区、期限和备注与系统观察信息分别显示；未知权利状态不被表述为已获授权。导出风险汇总列出被使用的待确认、过期、受限制或不可使用资产，以及引用它们的场次/镜头。
- **PH1-AC-016**：每项文本、图片和导入素材可查看人工创作、AI 生成或 AI 辅助修改状态；可获得的服务、时间、来源和修改记录关联到资产，无法取得的信息显示为未知。源资产与派生资产及其场次/镜头引用可追溯。
- **PH1-AC-017**：作品资料包默认包含用户选中的外部引用素材副本；用户明确排除或文件不可用时，导出预览和清单列明具体项目及路径，恢复后的作品将其标记为未随包提供，不显示为完整可用素材。
- **PH1-AC-018**：用户可为剧本/资料建立英文版本，与中文原文并存、对照修改并独立导出；编辑译文不得改变原文。首阶段不要求 AI 自动翻译。
- **PH1-AC-019**：资料库支持作品创建、打开、复制、备份、恢复到新位置、归档和删除；恢复前显示目标位置与范围。含已提交 WAL 事务的作品备份恢复后可重新打开，迁移/恢复失败不覆盖原作品或唯一备份。
- **PH1-AC-020**：外部 AI 任务首次使用前取得服务级授权；每次提交前显示服务和发送范围，允许移除上下文或取消；撤销后阻止新请求。作品内可查服务、用途、时间和内容范围的发送记录，以及已知的数据保存/删除信息；未知项明确标记。请求已发出后取消只表示尽力终止，不表示服务端未收到或已删除数据。
- **PH1-AC-021**：在作品、剧集、角色、场次、剧本段落、镜头或素材的上下文中可以发起助手对话；用户可检查和调整拟发送的上下文。解释和建议不会改变正式内容；明确要求生成或改写时，结果以候选形式进入预览、比较和确认流程。
- **PH1-AC-022**：用户可选择、启停和调整内容风险检查规则，并对首阶段支持的剧本文本、生成要求及参考图运行检查；已设置地区或平台方向时可作为检查上下文，但不宣称完成成片发布合规检查。每条结果显示相关内容、规则/依据、影响、判断来源和不确定性；用户可忽略、标记已处理或重新检查。一般提示不阻止保存或导出，检查不改写内容，也不宣称保证法律合规或平台审核通过。未执行或能力不支持的检查不得显示为通过。
- **PH1-AC-023**：在导入、预览和抽帧前后提供首阶段媒体兼容矩阵，按容器/编码、分辨率、帧率、时长/文件规模及可识别色彩属性，分别列出媒体探测、预览和抽帧的已支持、有限支持、待确认或不支持状态。矩阵取值由阶段 0 的代表性素材原型确定；未验证项目显示未知/待确认，不得表述为已支持。超出范围时说明可执行操作与限制。
- **PH1-AC-024**：可访问性验收覆盖首阶段的创作、剧本、分镜画布、候选审核、检查和交付流程，逐项记录适用成功准则的满足/未满足/不适用状态及理由；至少核对键盘与可见焦点、对比度与非颜色状态、辅助技术可识别的名称/状态及放大显示后的可操作性。分镜画布不得默认排除。对导出的 DOCX/PDF 单独记录语义结构、阅读顺序和辅助技术验证结果；没有验证的格式不得宣称可访问或符合 PDF/UA。

| 工作包 | 交付物 | 依赖 |

## 7. 首阶段需求追踪

下表仅说明首阶段承接的需求及其验收位置，不表示相应 RFC 的所有跨模态能力均在首阶段完成。需求阶段映射见[阶段路线](roadmap.md)；未列入首阶段的要求按该路线安排，不能默认为已实现。

| RFC-001 / REQ-PROJ-001–015、REQ-BIBLE-001–007、REQ-SCRIPT-001–010、REQ-BOARD-001–007 | 作品/剧集、创作圣经、故事与剧本、场次/分镜及图像参考；创作圣经引用规则首阶段仅覆盖文本、图片和本地素材 | PH1-AC-001–008、012、018–019 |
